# HTML-Cashbook
This is a cashbook that will work on every browser. 
And you can either store your data locally on your device or share it over multiple devices through a locally running git platform like gitea. 
**But be careful to not save your data on the gitea online, only do this on your home (NAS) server runing something like gitea.**

# Key features
-  Save your transactions in a .json file locally or on your server
-  Works on every device that has a browser
-  Add transactions: income, expenses, transfers
-  Have multiple accounts all in one place
-  Graphs and charts
-  See all your transactions and export them into a .csv file
-  Export monthly reports
-  Hide the numbers
-  Add cathegories
-  Light and Dark mode

# How to install and use
1. Download the .html file either from the home page or from the releases page [here](https://github.com/thaclownminion/HTML-Cashbook/releases). 
2. Double click the .html file to open it.
3. Set up if you want it to be on a git service (DO NOT PUT THIS ONLINE like on the official gitea or github) or locally on your laptop. 
4. If you chose to save it locally just select the folder you want the .json file to be and you are done!

## Disclaimer
- The live syncing won't work on firefox and safari due to them not supporting live file updates.
  You can still use it but you just have to manually update your .json file, don't forget this.
